# Arc-2 Reference Files

Folder ini berisi file pendukung untuk pengerjaan Arc-2.
Tidak mengganggu file asli di Arc-1.

## Isi

| File/Folder | Untuk Siapa | Isi |
|-------------|-------------|-----|
| `TASK_*.md` | Masing-masing anggota | Task list detail per orang |
| `arduino_firmware_arc2/` | Yuddha + Adinda | Template firmware serial untuk Arduino Mega |
| `web_starter/` | Yuddha | Template awal web app (HTML/JS/CSS) |
| `data_collection_tool.py` | Farel | Tools record dataset gesture |
| `DATASET_GUIDE.md` | Farel + Yuddha | Panduan cara bikin dataset gesture |

## Cara Pakai

1. Baca file TASK masing-masing
2. Kerjakan sesuai prioritas
3. Tanya Yuddha kalau ada yang kurang jelas
